# 引脚映射表

本文档依据 STM32CubeMX 生成的当前代码（`Core/Inc/main.h`、`Core/Src/gpio.c`、`spi.c`、`usart.c`、`i2c.c`、`scan.c`）整理，列出本项目实际使用的所有引脚及其功能。

## 外设复用引脚

| 外设 | 功能 | 引脚 | 方向 | 复用功能 | 说明 |
|------|------|------|------|----------|------|
| USART1 | TX | PA9  | 输出 | AF7 | 调试打印串口（`printf` 重定向到 USART1） |
| USART1 | RX | PA10 | 输入 | AF7 | 调试打印串口接收（暂未用） |
| USART6 | TX | PC6  | 输出 | AF8 | 蓝牙 HC-05 发送 |
| USART6 | RX | PC7  | 输入 | AF8 | 蓝牙 HC-05 接收（中断收字节入环形缓冲） |
| SPI3 | SCK | PC10 | 输出 | AF6 | DAC8563 `SCLK`（串行时钟） |
| SPI3 | MOSI | PC12 | 输出 | AF6 | DAC8563 `DIN`（串行数据输入，24 位写帧） |
| SPI3 | MISO | PC11 | 输入 | AF6 | 未使用（DAC8563 无数据回读） |
| SPI3 | NSS | PC12 相关 | - | SPI_NSS_SOFT | 软件控制 NSS，实际帧同步由 SYN(PA15) 兼任 |
| I2C1 | SCL | PB6  | 双向(开漏) | AF4 | 0.96 寸 OLED 屏幕 I2C 时钟 |
| I2C1 | SDA | PB7  | 双向(开漏) | AF4 | 0.96 寸 OLED 屏幕 I2C 数据 |

说明：SPI3 的 TX 使用 DMA2 通道，具体为 **SPI3_TX = DMA1_Stream5 / CH0**（由 CubeMX 分配，Normal 模式，字节对齐，Very High 优先级）。

## 通用 GPIO

| 引脚 | 功能宏 | 方向 | 配置 | 用途 |
|------|--------|------|------|------|
| PA6  | `Light_PA6` | 输出 | PP, Low | 激光/光源控制。置 `SET`=光源关，`RESET`=光源开（扫描启动路径中关闭） |
| PA15 | `SYN` | 输出 | PP, Very High | DAC8563 `SYNC`（帧同步/片选，低有效；拉低启动一帧，拉高锁存），高速翻转 |
| PD1  | `CLR` | 输出 | PP, Very High | DAC8563 `nCLR`（异步复位，低有效），默认置 `SET`（不复位） |
| PD2  | `LD` | 输出 | PP, Very High | DAC8563 `LDAC`（低有效负载），默认置 `SET` |
| PD3  | `PD3`(KEY1) | 输入 | Pull-up | 短按循环切换扫描形状：圆 → 正方形 → 长方形（宽:高=2:1）→ 圆 |
| PD4  | `PD4`(KEY2) | 输入 | Pull-up | 短按切换扫描状态：停止态启动，运行态停止（停止时 DAC 回中点） |
| PD5  | `PD5`(KEY3) | 输入 | Pull-up | 短按幅度 ＋10%（10%~100% 循环，100% 后回到 10%） |
| PE2  | `LED4` | 输出 | PP, Low | 指示灯 |
| PA2  | `LED2` | 输出 | PP, Low | 指示灯 |
| PA3  | `LED8` | 输出 | PP, Low | 指示灯 |
| PB10 | `LED1` | 输出 | PP, Low | 指示灯 |
| PB12 | `LED7` | 输出 | PP, Low | 指示灯 |

说明：按键已外接上拉，按下为低电平；ScanCtrlTask（app_tasks.c）约每 10ms 轮询一次并做下降沿检测（天然消抖）。PD3 循环切形状、PD4 启停切换、PD5 幅度 +10% 循环，与蓝牙下发的命令走同一套 scan 模块接口。需要更清楚说明每个指示灯对应面板位置，可补充。

## 无引脚外设

| 外设 | 说明 |
|------|------|
| TIM6 | 扫描点间隔定时器（内部时钟），无外部引脚；更新中断经 `HAL_TIM_PeriodElapsedCallback` 驱动 `Scan_TimerTick()` 逐点推进 |
| TIM7 | HAL 系统时基（时间片），无外部引脚 |

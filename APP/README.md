# BtScanGalvo 蓝牙控制 APP

BtScanGalvo 振镜扫描系统的蓝牙控制上位机，通过蓝牙（HC-05 透传 SPP）向 [Firmware](file:///d:/Embedded/BtScanGalvo/Firmware/README.md) 下发控制命令，实现形状切换、扫描幅度调节、启停/暂停与点间隔调整。

## 与固件的通信

- 传输：蓝牙模块 **HC-05**，以**透明串口桥**模式工作（一次性 AT 将波特率配为 115200），APP 侧无感知地走 SPP 串口数据。
- 对接串口：固件侧 **USART6**（HC-05，115200）。调试打印走 USART1，APP 不参与。
- 帧协议：自定义二进制帧，见下方《蓝牙命令协议》。实现需遵循 [bt_protocol.c](file:///d:/Embedded/BtScanGalvo/Firmware/Core/Src/bt_protocol.c) 的定义，保证 SOF/长度/CRC/ACK 语义一致。

## 当前状态

APP 目录目前仅有本文档，上位机源码尚未创建。协议以固件侧已实现的命令为准，APP 开发时按下表实现发送与回执解析。

## 蓝牙命令协议

帧格式（长度字段为 payload 长度，CRC8 覆盖 `CMD+Payload`）：

```
[SOF 0xAA][LEN][CMD][Payload][CRC8]
```

| CMD | 名称 | Payload | 说明 |
|-----|------|---------|------|
| 0x01 | 切换形状 | `shape` | 0 正方形 / 1 长方形（宽:高=2:1）/ 2 圆 |
| 0x02 | 调扫描幅度 | `0~100` | 满量程百分比 |
| 0x03 | 扫描启停 | `0`/`1`/`2` | 0 停止 / 1 启动 / 2 暂停 |
| 0x04 | 调点间隔 | 小端 `uint16`，≥5us | 相邻扫描点间隔 |
| 0xF0 | ACK 回执 | `err` | 固件回执：0 正常 / 1 未知命令 |

命令字 `0x80` 及以上保留扩展。固件侧由 BTTask 逐字节组帧、解析并投递到命令队列，ScanCtrlTask 在"安全点"执行，APP 每条指令发出后固件均应回 `0x01~0x04` 的正常 ACK（`0xF0, err=0`），未知命令回 `0xF0, err=1`。

## APP 功能界面

- 形状选择：对应 CMD 0x01，选择正方形 / 长方形 / 圆形。
- 幅度调节：对应 CMD 0x02，百分比滑条或步进调节。
- 启停控制：对应 CMD 0x03，启动、暂停、停止三个动作。
- 点间隔设置：对应 CMD 0x04，输入点间隔微秒数（≥5us）。

> 提示：以上四个控制项与面板按键（PD3/PD4/PD5）等效，二者共用同一套固件扫描接口，APP 仅是远程操作入口。

## 开发约定

- 所有工程使用 git 管理，新增源码后需在此目录补充构建/运行说明。
- 帧数据均按 8 位无符号处理；多字节数值采用小端序，示例：300us → `0x2C 0x01`。
- 协议以固件为准，APP 若新增命令需同时扩展固件并在此表登记。
